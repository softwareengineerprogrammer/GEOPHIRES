# Example: Superhot Rock (SHR) 4: Superhot EGS Project with Self-Flowing Wells (Production Wellbore Model 2)
#
# A 100 MWe-class superhot EGS project structured like Fervo_Project_Cape-6 (Cape Station Phase I): the same SAM
# Single Owner PPA economics, Gringarten reservoir model and fracture parameterization, but with the reservoir at
# superhot conditions (450 deg.C, 30 MPa at 3.5 km), self-flowing production wells and a surface power cycle run on
# the enthalpy and pressure of the wellhead stream, both modeled with the superhot-wellbore package:
#   Scott, S.W. (2026), Thermo-hydraulic drivers of superhot geothermal well performance, Geothermics, 141, 103784,
#   https://doi.org/10.1016/j.geothermics.2026.103784
# The Gringarten model supplies the thermal decline of the fractured reservoir; the coupled inflow-wellbore production wellbore model
# supplies the radial Darcy inflow, the isenthalpic expansion into the well and the bottom-to-surface thermohydraulic
# wellbore simulation (friction, gravity, kinetic energy, conductive heat loss), and hence the wellhead pressure,
# temperature and enthalpy; the Coupled Wellbore Power Cycle plant (Power Plant Type 10) converts that wellhead stream to
# electricity with a single-flash or binary cycle. The initial flow rate that delivers the target wellhead pressure of
# 10 MPa is solved for,
# the Gringarten decline is computed at that flow rate, and the flow rate is then held constant while the wellhead
# conditions respond to the reservoir decline, since GEOPHIRES carries one flow rate per well.
#
# Requires the superhot-wellbore package:
#   pip install git+https://github.com/softwareengineerprogrammer/superhot-wellbore.git
